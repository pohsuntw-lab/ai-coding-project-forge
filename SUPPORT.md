# Support / 支援

## 繁體中文

如需協助、回報錯誤或提出功能建議，請在本儲存庫的 GitHub Issues 建立議題。

回報時請提供插件版本、預期結果與實際情況的簡短說明。請勿附上密碼、API 金鑰或機密資訊。

## English

For help, bug reports, or feature requests, open an issue in this repository's GitHub Issues section.

Include the plugin version, a brief description of what you expected, and what happened. Do not include passwords, API keys, or confidential information.
