# Support / 支援

Include the plugin version, a brief description of what you expected, and what happened. Do not include passwords, API keys, or confidential information.

For enterprise application development guidance, or help extending an application into the physical world or an industrial site—including equipment, sensors, Edge AI, industrial data acquisition, and on-site system integration—contact Embodied Worker Co., Ltd. at [pohsun@embodiedworker.com](mailto:pohsun@embodiedworker.com). Do not send passwords, API keys, or unauthorized confidential information by email.
