# 教師發佈說明 / Publishing Guide for Educators

## 繁體中文

### 這個套件能做什麼

- 檢查插件與技能內容。
- 在 Codex／ChatGPT 桌面開發環境以本地 Marketplace 測試。
- 將 GitHub 儲存庫作為團隊 Marketplace 來源。
- 作為提交公開插件目錄的原始碼包。

### 重要限制

- 不能把 ZIP 直接傳給手機學生點擊安裝。
- 插件發布到公開目錄或學生可見的 Marketplace 前，手機無法搜尋與安裝。

### 建議發布順序

1. 用至少三個真實專案測試繁中與英文訪談、五份文件及 Codex 完工後續作。
2. 驗證文件一致性、GitHub 建檔、測試與預覽證據、發布授權、價值驗證、安全停止條件與語言切換。
3. 更新 GitHub 儲存庫與版本號。
4. 提交 OpenAI 插件審核。
5. 審核通過並公開後，提供公開頁連結給學生。

## English

### What this package supports

- Review the plugin and skill source.
- Test it through a local Marketplace in a Codex or ChatGPT desktop development environment.
- Use the GitHub repository as a team Marketplace source.
- Prepare a source package for the public Plugins Directory.

### Important limitations

- Students cannot install the plugin on a phone by opening the ZIP file.
- The plugin must be published in the public directory or a Marketplace visible to the students before mobile installation is available.

### Recommended publishing sequence

1. Test the Traditional Chinese and English interviews, all five outputs, and post-Codex continuation with at least three real projects.
2. Verify document consistency, GitHub setup, test and preview evidence, release authorization, value verification, safety stop conditions, and language switching.
3. Update the GitHub repository and version.
4. Submit the plugin for OpenAI review.
5. After approval and publication, share the public directory page with students.
